# Форсаж для телефона (Android та iOS)

Ті самі екрани, що у вебі (`apps/web`), зібрані всередину застосунку: відкриваються одразу, без завантаження з Vercel.
Дані — із сервера програми, як у вебі. Сканер — рідний сканер телефона (Google ML Kit), а не камера через браузер.

## Як зібрати Android

Збирає GitHub (на ПК магазину немає Java й Android SDK):

1. GitHub → репозиторій → **Actions** → **Mobile app** → **Run workflow** → `android`.
2. Через ~10 хвилин у цьому запуску внизу зʼявиться файл **forsage-android** — у ньому `app-debug.apk`.
3. Файл передати на телефон і відкрити; Android спитає дозвіл «встановлювати з цього джерела» — дозволити.

Перший запуск сканера на новому телефоні: Android один раз довантажує модуль сканера Google (кілька секунд), потім
треба натиснути сканер ще раз.

**Оновлення.** Поки застосунок підписується тимчасовим ключем збірки, нова версія не стає поверх старої: стару треба
видалити й поставити нову (вхід у програму доведеться повторити). Щоб оновлювалось поверх — потрібен постійний ключ
підпису (ще не зроблено).

## Як зібрати iOS

Та сама кнопка з `ios` перевіряє, що проєкт збирається на Mac у хмарі. Щоб поставити на iPhone, потрібні:

1. Обліковий запис **Apple Developer** (99 $ на рік) — реєструє власник на своє імʼя.
2. Сертифікат і профіль підпису з цього запису — додаються в налаштування збірки як секрети.
3. Тоді збірка викладає застосунок у **TestFlight**, звідки він ставиться на iPhone за запрошенням.

Кроки 2–3 ще не налаштовані: без облікового запису Apple їх не зробити.

## Для розробника

```bash
pnpm --filter mobile run build:web   # екрани → apps/web/dist-mobile (VITE_MOBILE_BUILD=1)
cd apps/mobile && npx cap sync android
```

- Налаштування оболонки — `capacitor.config.ts` (appId `ua.forsage.crm`).
- Рідний сканер — `apps/web/src/lib/nativeScan.ts`; «курок» сканера той самий, що у вебі (`LiveCameraScanner`).
- Сервер дозволяє адреси застосунку `https://localhost` (Android) і `capacitor://localhost` (iOS) — `server/src/index.ts`.
- Публічні налаштування для збірки екранів — змінні репозиторію `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`.
