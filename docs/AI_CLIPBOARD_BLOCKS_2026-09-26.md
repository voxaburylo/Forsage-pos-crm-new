# 26.09.2026 — список товарів із буфера замість таблиці

## Причина й межі

Користувач вставляв текст із чотирма нумерованими описами ключів, полями
«Кількість», «Закупівля» та «Ціна продажу». Локальний читач підтримував
таблиці з колонками, але не такий список. Він передавав текст загальному
AI chat; вільна відповідь без bulk-action відхилялася. Повідомлення помилково
говорило про фото. Сирої відповіді Gemini в діагностиці немає, тому її
точний вміст не стверджується.

## Виправлення

- Нумеровані описи з явними полями кількості та закупівлі читаються локально
  в наявному worker. Не потрібні інтернет, ключ ШІ або серверний вхід.
- Збережено всі 4 назви, 18″ / 20″, стандартний / посилений, описи та одиниці.
  Номер рядка не стає артикулом; штрихкод не вигадується.
- Закупівля: 141 / 162 / 165 / 186 грн, кількість по 1, разом 654 грн.
  Продаж 550 / 600 / 650 / 700 не підміняє закупівлю. Як і раніше,
  роздріб розраховує звичайна логіка націнки у накладній.
- «Приблизно 186» зберігається лише як пропозиція для чернетки, з явним
  попередженням у перевірці та примітках документа. Точну закупівлю слід
  перевірити в звичайній чернетці перед проведенням.
- Відсутні / повторні поля, хибні числа, порушена нумерація, різні валюти
  закупівлі та несумісні одиниці не дозволяють мовчки пропускати товари.
- Схожі картки, підтвердження та єдина непроведена накладна використовують
  наявний маршрут. Нових кнопок або вікон не додано.
- Порожня AI-відповідь тепер розрізняє текст і фото, зберігає вкладення.
  У чорну скриньку потрапляє лише фіксований клас помилки без тексту товарів.

- 956 web-тестів пройшли; один старий тест потребує окремого XLSX-fixture
  і пропущений. 22 нові тести саме для списків із буфера.
- 52 цільові desktop-перевірки: імпорт, зіставлення карток та діагностика.
- TypeScript web, lint та desktop/web production build пройдені.
- Реальне React-вікно + worker, мережа заблокована: усі 4 рядки / 654 грн,
  попередження приблизної закупівлі, до підтвердження немає запису,
  подвійний click створює одну тестову чернетку. Фото/Excel/валюта/VIN —
  попередні UI-регресії пройшли. API і база замінені тестовими.
- Зібраний worker у Electron file:// + sandbox без мережі: той самий текст,
  усі 4 позиції й попередження пройшли; перевірка Excel також пройшла.
- Попередні виправлення у цьому пакеті: Windows safeStorage/денний вхід
  на ізольованій SQLite; повні чеки 1/2/18/45 позицій, усі підсумки
  та кінець чека на місці. Фізичний друк не запускався.
