# Підключення ШІ після локального входу — 26.09.2026

## Причина

Локальний вхід через PIN/запам'ятований акаунт не є серверною авторизацією.
Desktop навмисно не зберігає серверні токени між запусками. Після перезапуску
локальна сесія лишалась чинною, але перевірка ШІ отримувала 401.
Інтерфейс помилково називав усі збої перевірки відсутністю інтернету.

Чорна скринька підтвердила unlock-remembered. Публічний endpoint версії
відповів 200, а AI status без авторизації — 401. Це не тест розпізнавання
через Gemini з чинним акаунтом користувача.

## Зміни

- Розділено помилки сесії, прав, мережі, таймауту й сервера.
- При відсутності серверної сесії показується «Підключити ШІ» з паролем
  поточного акаунта (не PIN). Локальний користувач, роль і база не змінюються.
- Авторизація виконується ізольованим клієнтом без збереження пароля/токенів.
  Перевіряються ID, магазин, активність та право входу до приєднання сесії.
- Подвійне натискання, вихід/зміна акаунта, пізня відповідь та таймаут захищені.
  Пароль очищається одразу після натискання й не потрапляє до діагностики.
- Повтор перевірки й повернення мережі не стирають текст/вкладення.
  Закінчення сесії під час розпізнавання також відкриває підключення.
- Excel/таблиці, які можна розібрати локально, не залежать від підключення ШІ.
- У чорну скриньку записуються лише фіксовані класи AI_STATUS_*, без фото,
  паролів, токенів або сирої відповіді сервера.

## Перевірки

- 924 web-тести пройдено, один optional XLSX fixture пропущений.
- 19 тестів підключення, 10 класифікатора, один structured desktop 401.
- Реальний React UI із синтетичним сервером: неправильний пароль, повторне
  натискання, збереження фото/тексту, прострочення сесії під час розпізнавання,
  повернення мережі, попередні Excel/фото/VIN/підтвердження накладної.
- Web lint, production TypeScript/build, desktop types; 30 цільових desktop
  тестів (black box і warehouse recovery) після останньої зміни пройдено.
- Повні 778 desktop-тестів пройдено на попередньому складському пакеті;
  після цього desktop-зміна стосувалася лише класифікатора AI-помилок.
- Перевірено manifest/package та складські сценарії з упакованого ASAR.
