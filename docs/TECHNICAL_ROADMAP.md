# Технічне зміцнення Форсажу — актуальний план

Початок: 23.09.2026. Джерело істини — локальна база головного ПК.
План об'єднує погоджені 16 напрямків; попередні протоколи збережені як історія.

## Правила виконання

- 26.09: без нових функцій і додаткових кнопок без окремого погодження. Поточна робота — виправлення та спрощення. Вхід: логін/пароль, запам’ятовування до кінця дня, скасування лише повним «Вийти» (і перевіркою актуальних прав); без PIN.

- Не змінювати робочі залишки, платежі, працівників чи документи автоматично.
- Відтворення, аварійні сценарії й відновлення — на ізольованих тестових базах.
- Зберігати наявні незакомічені зміни. Не запускати старі repair/cleanup-скрипти.
- Для кожного пакета: причина, обсяг, регресійний тест, перевірки та статус встановлення.
- Код / перевірено / встановлено / опубліковано — різні стани.
- EXE замінюється лише після закриття програми. Публікація і зовнішнє сховище — окремо.
