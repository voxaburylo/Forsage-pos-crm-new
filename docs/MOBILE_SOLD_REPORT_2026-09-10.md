# Мобільний звіт проданих товарів — 10.09.2026

- На екранах до 768 px звіти «Сьогодні» та «Продані товари» використовують картки замість таблиць мінімальною шириною 620/900 px.
- Є повна назва, артикул, штрихкод, полиця, чиста продана кількість, сума, залишок і середня ціна продажу. Повернення показані окремим поясненням; розрахунки звіту не змінювалися.
- Середня ціна = виручка продажів / продана кількість, не поточна ціна картки і не сума після повернення / чиста кількість. Для рядків лише з поверненнями ціна не вигадується.
- Довгі ідентифікатори переносяться. На телефоні список не має власної вертикальної прокрутки; використовується основна прокрутка сторінки.
- Вкладки звіту на телефоні замінені компактним вибором. Поля дат обмежені шириною своїх колонок; великі підсумки не розтягують сторінку. На ПК таблиці збережено.

Перевірка ізольованого UI з 30 тестовими товарами: Chromium 320/375/430 px, обидва звіти. Ширина документа й основного скролера дорівнює ширині екрана; горизонтального переповнення та внутрішнього скролера списку немає; останній товар доступний. На 1280 px видима таблиця. Знімок перевірено візуально. Це не живий тест Safari на фізичному iPhone.

Додано два регресійні тести компонента. Робочі звіти/остатки/платежі під час перевірки не змінювалися.

Загальний verify пройдено: 433 web + 345 desktop + 246 server = 1024 тести, типи і lint. EXE перескладено в існуючий `apps/desktop/release/Forsage-0.1.0-portable.exe`; ярлик «ФОРСАЖ — КАСА» веде на нього. Electron smoke з тимчасовою SQLite та резервною копією пройдено. Тимчасовий UI-стенд видалено після перевірки.
