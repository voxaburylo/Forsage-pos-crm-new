# Підключення ПК менеджера без інтернету

Головна база залишається на ПК каси. Другий ПК працює через локальну мережу;
інтернет для підключення, входу та передачі замовлень не потрібен. Перший вхід
потребує ввімкненого головного ПК з відкритим «Форсажем».

## Одноразове підключення

1. Спочатку встановіть сумісну нову збірку на обидва ПК. Старий EXE ще не має
   початкового майстра та отримання оновлень через мережу.
2. На головному ПК власник відкриває «Налаштування» → «Робота компʼютерів через
   локальну мережу», вибирає «Головний ПК каси», працівника для другого ПК
   і натискає «Зберегти мережу». Адреса й код зʼявляються в цьому ж розділі.
3. На чистому ПК менеджера запустіть `Forsage.exe` з розпакованої папки,
   не зсередини ZIP. Програма шукає головний ПК автоматично. Виберіть його,
   якщо знайдено кілька, та один раз введіть код із головного ПК.
4. Увійдіть за звичайним номером телефону та паролем саме того працівника,
   якого власник дозволив у налаштуваннях. Пароль перевіряє головний ПК.

Код підключення не є паролем працівника. Дані магазину, чужі паролі та
товарну базу не потрібно копіювати. На повторних запусках код не запитується;
зберігається чинний порядок входу за паролем і запамʼятовування на день.

## Якщо компʼютер не знайдено

Обидва ПК мають бути в одній локальній мережі. Підключення через свіч
підтримується, у тому числі локальні адреси `169.254.x.x` без DHCP.
Якщо Windows блокує автоматичний пошук, увімкніть «Ввести адресу вручну»
і введіть адресу, показану на головному ПК. Типовий порт — `3210`.

На довіреній мережі магазину Windows має дозволяти «Форсажу» вхідні
підключення: TCP на вибраному порту (типово `3210`) та UDP `3211` для пошуку.
Не вимикайте брандмауер цілком і не відкривайте ці порти в інтернет.
Без TCP-доступу ручна адреса також не допоможе. Налаштування Windows
програма самовільно не змінює.

## Коли головний ПК вимкнений

Після першого успішного входу можна ввійти з перевіреним локально паролем,
якщо головний ПК саме недоступний. Невірний пароль, заборона доступу або
несумісність не обходяться через кеш.

Офлайн записується тільки зміст замовлення. Оплати, видача, прихід,
ревізія та зміна залишків потребують звʼязку з головним ПК. Замовлення
автоматично передаються після відновлення звʼязку в сесії їхнього автора;
невизначена відповідь не створює дубль. Непередані замовлення забороняють
перепривʼязку до іншого магазину та заміну кешованого працівника.

## Оновлення з головного ПК

Після одноразового оновлення обох ПК наступні сумісні portable-збірки
отримуються з головного ПК у фоні: після входу й приблизно кожні пʼять
хвилин. На головному ПК має бути запущена нова версія програми.

Передається тільки файл програми, не база. Другий ПК перевіряє версію,
розмір і контрольну суму. Поки ви працюєте, EXE не замінюється. Після
звичайного закриття підготовлена версія встановлюється на те саме місце;
попередній файл зберігається для відкату. Наступний запуск — звичайним ярликом.

Обрив завантаження не замінює робочий файл. Стара версія не встановлюється
поверх новішої. Якщо результат встановлення невідомий або Windows не
дозволяє заміну, автоматичних примусових повторів немає: стан зберігається
для перевірки. Код підключення й локальні замовлення оновлення не стирає.

## Приймання на двох ПК

Перед роботою менеджера потрібно перевірити саме вашу мережу: пошук головного
ПК, вхід дозволеного працівника, читання наявного замовлення, повторний запуск
і доставку наступної сумісної версії. Розробницькі тести на ізольованих базах
не замінюють цю фізичну перевірку.
