# Простий вхід на календарний день — 26.09.2026

## Узгоджена поведінка

- Лише логін (номер телефону) і пароль. PIN та перемикач користувача прибрані.
- Успішний локальний вхід автоматично зберігається до 00:00 наступного дня за Києвом.
- Закриття й повторний запуск програми в цей день не потребують пароля.
- Повний «Вийти» видаляє дозвіл; наступний вхід знову з паролем.
- Немає блокування через 5 хвилин простою, сон чи блокування Windows.
- Вимкнення/видалення працівника, зміна пароля, логіна або ролі скасовують доступ.
- Звичайні права перевіряються локально. Відсутність інтернету не блокує роботу.
- Після оновлення старий PIN-дозвіл не переноситься автоматично: один раз потрібен пароль.

## Реалізація без нових функцій

Денний дозвіл зашифрований Windows safeStorage, містить дату, користувача,
магазин і відбиток актуальних облікових даних. Сам пароль і PIN у ньому
не зберігаються. Відновлення не продовжує термін. Переведення годинника
назад, пошкоджений дозвіл або помилка розшифрування не дають доступу.

Main створює дозвіл лише після перевірки пароля. Прибрані IPC для довільного
запам’ятовування, PIN-розблокування та політики PIN. Старі колонки БД
залишені для сумісності, без руйнівної міграції. LoginSecurityCard і
LockScreenOverlay видалені, не приховані CSS.

Збережено блокування захищених дій після завершення дня без знищення
відкритої форми. Там можна повторно увійти паролем або повністю вийти.
При повному виході скасовуються фонові повтори авторизації; запізнілий
результат входу/відновлення не повертає користувача. Вихід не зависає
через сервер, але не повідомляє успіх, якщо локальний дозвіл не видалено.

ШІ як і раніше потребує серверної авторизації. Дозвіл локального входу
не підміняє серверний токен; пароль заради ШІ не зберігається.
