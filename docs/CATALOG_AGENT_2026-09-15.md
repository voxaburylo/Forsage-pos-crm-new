# AI-агент: наведення ладу в локальному каталозі — 2026-09-15

## Інтерфейс
- Адміністрування → AI-агент, лише власник/адміністратор у локальній програмі.
- Прибрано саме кнопки фото-AI зі списку поступлень і сторінки приймання. Старий механізм фото/помічника збережено, доступний через «Помічник / фото».
- Локальна перевірка назв, артикулів, категорій, націнки і можливих дублів. Поріг низької націнки налаштовується (типово 15%): це зауваження, не доказ помилки.
- Gemini перевіряє по 25 карток, за один ручний запуск 25/100/500 товарів. Без автоматичного запуску всього каталогу чи нескінченних повторів. Продовження з неперевірених карток.
- 50 зауважень на сторінку; явний перегляд «було → стане», вибір і підтвердження. Зупинка після поточного запиту. Пам'ять перевірки між вкладками до закриття програми, окремо для користувача; змінені картки відкидаються за відбитком.

## Межі та безпека
- Жодних змін під час сканування: SQLite readOnly у робочому потоці з узгодженим знімком.
- Перед підтвердженим записом — штатна резервна копія. Пакет до 100 товарів атомарний та ідемпотентний, з журналом дій і повторною перевіркою актуальних карток.
- Дозволені лише name, sku, category_id, retail_price. Залишки, закупка, штрихкоди, історичні чеки та документи не змінюються.
- SKU тільки замість порожнього/AUTO, однозначно присутній у назві, не частина іншого номера, не в'язкість/об'єм. Не дозволені колізії артикулів.
- Переклад зберігає цифри, технічні коди та бренд. Категорії тільки існуючі.
- Ціна лише з чинної таблиці націнки та штатного округлення; довільні/нульові/null ціни заблоковані.
- Видалення означає м'яке вилучення порожнього підтвердженого дубля. Ненульовий залишок, будь-які посилання документів/історії, додаткові номери чи окремі дані блокують його. Повне злиття історичних карток НЕ реалізовано; подібна назва не доводить тотожність.
- Новий серверний метод /api/v1/ai/catalog-review тільки для owner/admin. Він отримує назви/артикули/бренди/категорії та повертає пропозиції, без доступу до мутацій каталогу. Дані запиту вказані як недовірені, відповідь структурована та перевірена.
- Веб залишається переглядовим. Запис тільки локально через перевірені IPC-команди. Новий серверний метод ще потребує публікації; запитано окреме підтвердження GitHub/Vercel.

## Перевірки
- desktop: 455 тестів; web: 518; server: 279. Усі пройшли, як і 4 перевірки типів (desktop/web/server/api).
- Playwright на синтетичних даних: пагінація 50+1, жодного запису до підтвердження, зупинка AI зі збереженням пакета, повернення між вкладками, ширини 1200/390 без горизонтального переповнення основної панелі. Продукційні дані не змінювалися.
- Native Electron smoke: агент у робочому потоці сканує і змінює тимчасову базу; повтор запиту не дублює аудит, залишок 3 збережений. Загальний штатний DB smoke також успішний.
- Реальний каталог: 14 463 товари, перевірка worker readOnly ~0,83 с. 76 можливих пар дублів, 0 безпечних для простого видалення. Жодної фактичної чистки не виконувалось.
- Реальний Gemini, один синтетичний товар: «Фильтр масляный MANN W811/80» → «Фільтр масляний MANN W811/80», SKU W811/80, надана категорія масляних фільтрів. Успішно; тільки витрата одного AI-запиту/запис лічильника використання.
