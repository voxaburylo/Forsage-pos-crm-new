# Смоук-чеклист після деплою (5 хвилин)

> Якщо всі кроки проходять — «хребет» бізнесу живий. Виконувати після КОЖНОГО деплою.

## Перед стартом
- [ ] Міграції з `supabase/migrations/` застосовані (остання має збігатися з кодом; на 2026-06-11 — `109_reserve_skip_canceled_items.sql`)
- [ ] `GET /api/v1/health` повертає `{"status":"ok"}`

## 5 кроків ядра
1. **Замовлення в магазині**: Замовлення → Нове → вибрати клієнта → позиція з каталогу →
   «Оформити замовлення» → замовлення відкрилось зі статусом «Нове».
2. **Заказ із чату**: відкрити Боти/Месенджер → останній чат → «Створити замовлення з чату»
   (або надіслати тестове повідомлення боту і перевірити, що воно з'явилось).
3. **Оплата**: на картці замовлення «Внести оплату» (частина суми) → «Сплачено» оновилось,
   касова операція з'явилась у касі.
4. **Видача**: позиції «Приїхало» → POS → «Видати» → чек закрито, борг 0, статус «Виконано».
5. **Прихідна накладна**: Постачальники → Прихідні накладні → Нова → товар, кількість, ціни →
   провести → залишок товару збільшився, роздрібна перерахувалась за націнкою.

## Додатково (раз на тиждень)

- [ ] Експорт XLSX: Звіти → 7 днів → «Експорт в Excel» — файл відкривається.
