# Архів документів

Тут лежить те, що вже не описує систему такою, якою вона є, але викидати шкода:
за цими файлами видно, чому щось зроблено саме так. **Не звірятися з ними як з
актуальним станом** — для цього є документи в корені.

Перенесено 06.09.2026, коли в корені зібралося 13 документів на 6030 рядків,
серед них чотири різні аудити й два роадмапи, що частково суперечать один
одному.

## Чим користуватись натомість

| Питання | Актуальний документ |
|---|---|
| Як влаштована система і чому локальна база головна | `LOCAL_FIRST_ARCHITECTURE.md` (корінь) |
| Де що лежить у репозиторії | `PROJECT_LAYOUT.md` (корінь) |
| Що і чому виправляли, з датами й комітами | `FIX_JOURNAL.md` (корінь) |
| Що приводимо до ладу зараз | `REFACTOR_PLAN.md` (корінь) |
| Як деплоїти | `DEPLOY.md` (корінь) |

## Що тут лежить

| Файл | Чим був | Чому в архіві |
|---|---|---|
| `ARCHITECT_PLAN.md` | найбільший план архітектури (1042 рядки) | описує намір, а не те, що вийшло; частина не реалізована |
| `SYSTEM_OVERVIEW.md` | загальний огляд системи | писався до переходу на локальну касу |
| `POS_ARCHITECTURE.md` | будова каси | те саме, до переходу на десктоп |
| `AUDIT.md`, `AUDIT_REPORT.md`, `FINAL_PRODUCT_AUDIT.md`, `POS_AUDIT_REPORT.md` | чотири аудити різних періодів | знахідки або виправлені, або перенесені у `FIX_JOURNAL.md` |
| `ROADMAP.md`, `PRODUCT_ROADMAP.md` | два роадмапи | суперечать один одному; що робимо зараз — у `REFACTOR_PLAN.md` |
| `FORSAGE_UX_VISION.md` | бачення інтерфейсу | здебільшого зроблено |
| `DEPLOY_SMOKE.md`, `LOCAL_FIRST_PREFLIGHT_CHECKLIST.md` | разові чеклісти перед запуском | свою роль відіграли |
| `FORSAGE_ORDERS_FIX_PLAN_1.md.txt` | план правок по замовленнях | виконано в червні 2026 |
