## P0 — Денежный поток и приём заказов не должны падать

Это «позвоночник»: **приём (магазин / Telegram / Viber / WhatsApp) → карточка заказа → поставщик/лист ожидания → оплата → видача.**

- [x] 🔴 **Telegram-бот не отвечал** — невалидный `allowed_updates` (`photo`/`voice`) ронял polling. Исправлено; нужен **передеплой бэкенда** + проверка живым сообщением. ⚠️ Один токен = один запущенный сервер (иначе `409 Conflict`).
- [x] 🔴 **Viber/WhatsApp — выяснено: НЕ реализованы** (это не баг, а ненаписанная фича). В коде только Telegram: `initMessengers` синхронизирует лишь telegram-токен, `sendMessageToChat` шлёт только в Telegram, webhook'ов приёма для Viber/WhatsApp нет. Фронт уже честно помечает их «невдовзі» (disabled). Добавил понятную ошибку при попытке отправки в не-Telegram канал. **Решение для вас:** если нужны Viber/WhatsApp — это отдельный проект (нужны аккаунты/провайдеры, webhook). См. «План каналов» ниже.
- [ ] 🟠 **Заказы вне CRM (WhatsApp/Viber вручную).** Сейчас заказы из этих мессенджеров менеджер заводит руками. Пока каналы не интегрированы — это нормальный обходной путь; ускорить можно «создать заказ из чата» (уже есть для Telegram).
- [ ] 🔴 **Сквозной smoke-тест после каждого деплоя** (5 шагов): создать заказ в магазине → принять заказ из чата → внести оплату → выдать → провести приходную накладную. Если все 5 проходят без ошибок — ядро живо. Стоит оформить как короткий чеклист в README/деплое.
- [ ] 🟠 **Видача требует полной оплаты** (в кассе `completeOrder` блокируется при остатке) — логика верная, но проверить, что путь «частичная предоплата → доплата на кассе → видача» проходит гладко по всем каналам.

### План каналов Viber / WhatsApp (для вашего решения)
Чтобы реально подключить — нужны бизнес-решения и аккаунты (это не «правка», а интеграция):
- **Viber** — самый реальный. Бесплатный *Viber Bot API*: создать публичный аккаунт/бота → получить токен → завести webhook на ваш бэкенд (URL). Объём: приём + отправка, ~1 день. Нужен только Viber-бот.
- **WhatsApp** — сложнее, нужен провайдер (на выбор): **Meta WhatsApp Cloud API** (официально, дёшево, но нужен Facebook Business + номер + шаблоны для исходящих), либо **Twilio / 360dialog** (проще старт, но платно). Объём: больше, + правила WhatsApp (нельзя писать первым без шаблона). Нужно ваше решение по провайдеру.
- **Что сделаю я, когда будете готовы:** дайте Viber-бот токен (или выбор WhatsApp-провайдера + доступ) — напишу адаптер приёма/отправки в общий механизм каналов, чтобы чаты падали в ту же «Боти/Месенджер».

## Сквозные принципы «удобно и быстро» (рекомендации)

1. **Меньше кликов на главном пути.** Заказ и продажа — за минимум действий: автоподстановки (клиент, авто, цена, остаток), быстрые кнопки, горячие клавиши, минимум обязательных полей.
2. **Одна вещь — одно место.** Не дублировать настройки/действия по разным экранам.
3. **Ошибки видимы и понятны.** Любая ошибка интеграции (ПРРО, термінал, Telegram) — понятный тост + запись в журнал, а не «тихо не сработало».
4. **Состояние всегда понятно.** Цветные статусы, счётчики на вкладках, «Сплачено/Борг» в списках (уже частично есть — расширять).
5. **Идеал достижим как процесс, а не как разовое событие.** Ядро надёжно → дальше список улучшений тает сверху вниз.
