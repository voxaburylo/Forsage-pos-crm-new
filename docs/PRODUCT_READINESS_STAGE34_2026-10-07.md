# Пакет 34 Цілісність імпорту прайсів

07.10.2026 усунені конфлікти внутрішніх ID, які могли непомітно
пропустити запис або переприв’язати рядок іншого прайсу.
Це підготовчий захист для перенесення залежностей при злитті
постачальників, а не саме перенесення прайсів.

## Виправлення

На сервері ID об’єкта в операції та в її даних мають збігатися.
Регістр UUID нормалізується. Одна партія не може містити повторний
ID, навіть коли повтор потрапив до наступної порції з 400 записів.

Перед заміною перевіряється, що наявні рядки належать тому самому
постачальнику, складу й організації. Наявний запис імпорту не можна
прив’язати до іншого постачальника. Для одиночного редагування
наявна можливість свідомо змінити постачальника збережена.

Кожний запис перевіряється за фактичним результатом бази.
Якщо запис пропущено без винятку, вся транзакція скасовується:
старий прайс, нові рядки й журнал імпорту не змінюються частково.
Видалення використовує те саме блокування каталогу, що й імпорт.

Локальне приймання копії відхиляє запис іншої організації та
конфлікт із наявним чужим ID. Захист продубльовано в умові
оновлення бази. Незавантажені локальні зміни залишаються
недоторканими; пропущене оновлення не позначається як застосоване.
Історичні посилання на архівного постачальника з пакета 33 збережені.

## Перевірки

До виправлення відтворені 4 локальні та 13 серверних невдалих сценаріїв.
Додано 27 регресійних тестів, зокрема навмисне безпомилкове
пропускання запису базою та повний відкат заміни після такого пропуску.

- Локальна програма: 1488 тестів у 135 файлах, усі пройшли.
- Сервер: 1608 тестів у 97 файлах, усі пройшли.
- Разом повторно виконано 3096 тестів.
- Typecheck та збірки desktop і server пройшли.
- Electron перевірив 13 умов на зібраному dist.
- Вебінтерфейс не змінювався; його повний набір цього кроку не повторювався.
- Робочі бази, чеки, залишки, серверні дані й принтери не змінювалися.

GitHub run 37596254844 попереднього пакета 33 завершився успішно.
Це не результат CI для нових змін пакета 34.

## Встановлення і наступний крок

Пакет 34 підготовлено у коді та перевірено. Новий portable EXE
цього кроку не пакувався, встановлена версія
20261007T052142-d87b0051d797 залишилася без змін.
Нові зміни ще не опубліковані на GitHub чи Vercel.

Перенесення прайсів, імпортів, замовлень і правил закупівлі
при злитті постачальників залишається заблокованим.
Наступний крок: незмінний знімок цих залежностей, узгоджений
перехід обох копій та повторна доставка після злиття.
Пошкоджені числові значення прайсів і порядок застосування
старих копій також потребують окремих перевірок; цей пакет
не оголошує всю синхронізацію прайсів завершеною.
