# Пакет 104 Встановлення оновлення і відкат Windows

Власник дозволив оновлення: «Оновлюй уже не працюю». На початку перевірки
Forsage закритий. Основна база й непідтверджені товари не змінюються;
налаштування працівника для другого ПК не вибираються автоматично.

## Причина затримки встановлення

CI38403627415 для пакета103 завершився невдачею:3125 desktop-тестів PASS,
один FAIL. Невдала перевірка аварійного відкату після заміни EXE, не каталогу.
Локально її раніше пропускали через відкриту робочу програму. Тепер помилка
відтворена на синтетичних файлах: Windows PowerShell перетворює аргумент
`$null` для `File.Replace` на порожній рядок, і відновлення старого EXE
припиняється з повідомленням про неправильний шлях.

Мінімальне виправлення: типізований C# виклик `File.Replace` передає справжній
null для необов'язкового резервного шляху. Перевірки hash, власника файла,
відсутності запущеної програми та атомарність заміни залишаються чинними.
Тест додатково перевіряє очищення власних тимчасових файлів і незмінність
синтетичної бази; неперевірений сторонній rollback-файл не переписується.
